Configuring: trade log

Once the bot is set up:

  1. Enable developer mode (if not already): User Settings → "Advanced" → turn on "Developer Mode".

  1. Copy the channel ID: right click the channel that should record trades → "Copy Channel ID".

  1. In config.yml find discord-bot → log-trades → channel, paste the ID and set enabled to true. Restart the server and logging starts.
discord-bot:
  # ...
  log-trades:
    enabled: true
    # channel ID for the trade log
    channel: '123456789012345678'

The trade log channel should also be read-only (only the bot posts), otherwise chat scrolls it away.
