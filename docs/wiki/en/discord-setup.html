Setting up the Discord bot

Creating the bot

  1. Open https://discord.com/developers/applications/ and click "New application" to create one.
  2. Invite the bot to your server: replace REPLACE-HERE-THE-ID below with the bot ID and open the URL in a browser:

https://discordapp.com/oauth2/authorize?client_id=REPLACE-HERE-THE-ID&scope=bot

The bot ID is shown under "General Information".

  1. Get the token: go to the "Bot" page, click "Reset Token" and save the token somewhere safe (it is shown only once).

  1. Put the token into config.yml under discord-bot → token and set enabled to true.
