安装

前置条件

只需要下载一个 jar：Nascraft-<版本>.jar。插件启动时会读取服务端版本，自动选择合适的 GUI 后端（InvUI 1.x 或 2.x），不需要再按版本对号入座。

服务端版本 Java GUI 后端（自动选择）
Paper / Purpur 1.21.11 21 InvUI 1.x
Paper / Purpur 26.1.1 / 26.1.2 25 InvUI 2.x
Paper / Purpur 26.2 25 InvUI 2.x
Paper / Purpur 26.3 25 InvUI 2.x
Paper / Purpur 26.4+ 25 待适配发布

注意：

  • 所有依赖（bStats、InvUI 1.x / 2.x、item-nbt-api）都已打包进 jar，干净服务端丢进 plugins/ 就能启动。
  • 只保证 Spigot / Paper / Purpur 的兼容性；Mohist 等其他 fork 不保证可用。
  • 从 26.4.5.2 起不再提供「按版本区分」的多个 jar，旧的多版本 jar 请直接删除，只保留一个。
  • 26.1 系列官方只发布了 26.1.1（alpha）与 26.1.2（stable），没有「26.1」这个独立版本号。
  • 启动日志里会打印当前使用的后端，例如 GUI backend: invui 2.x (Bukkit 26.1.2-..., Java 25...)，可据此确认识别正确。

安装步骤

第 1 步：检查依赖

确认已经安装 Vault 和一个经济插件（例如 EssentialsX）；没有 Vault 的话可以在这里下载（Vault 缺失时插件仍能启动，但经济功能不可用）。

第 2 步：下载 jar

在 Releases 页面下载最新的 Nascraft-<版本>.jar，放到服务端的 plugins/ 目录。

第 3 步：重启服务端

重启后插件会生成配置文件，接下来就可以进入配置了。

升级到新版本时，config.yml 会按 config-version 自动合并新增的配置项：旧文件先备份为 config-backup-*.yml，你自己改过的值与原注释都会保留，不需要手动比对。

第 4 步（可选）：扩展

  • AdvancedGUI：在游戏内放置触屏版行情界面，见 AdvancedGUI 扩展。
  • Discord 扩展：把市场搬进 Discord，见 Discord 扩展。
  • QQ 机器人：支持两种接入方式——个人 QQ 走 OneBot v11 桥接，官方的 QQ 机器人走开放平台 API v2；都能用 QQ 群或私聊查价、看持仓、收成交播报，见 QQ 机器人。
