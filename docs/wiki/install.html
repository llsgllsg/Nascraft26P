安装

前置条件

插件提供三个构建版本，请按服务端版本选择对应的 jar：

服务端版本 Java UI 依赖 说明
Paper / Purpur 1.21.11 21 InvUI 1.x 1.21 系列
Paper / Purpur 26.2 25 InvUI 2.3.0 26.2 系列
Paper / Purpur 26.3 25 InvUI 2.5.1 26.3 系列，推荐

注意：

  • 所有依赖（bStats、InvUI、item-nbt-api）都已打包进 jar，干净服务端丢进 plugins/ 就能启动。
  • 只保证 Spigot / Paper / Purpur 的兼容性；Mohist 等其他 fork 不保证可用。
  • 用错版本的 jar 会报错，请务必对号入座。

安装步骤

第 1 步：检查依赖

确认已经安装 Vault 和一个经济插件（例如 EssentialsX）；没有 Vault 的话可以在这里下载。

第 2 步：下载 jar

在 Releases 页面下载对应版本，放到服务端的 plugins/ 目录。

第 3 步：重启服务端

重启后插件会生成配置文件，接下来就可以进入配置了。

第 4 步（可选）：扩展

  • AdvancedGUI：在游戏内放置触屏版行情界面，见 AdvancedGUI 扩展。
  • Discord 扩展：把市场搬进 Discord，见 Discord 扩展。
  • QQ / OneBot v11 桥接：Nascraft26P 新增，用 QQ 群查价、看持仓、收成交播报。
