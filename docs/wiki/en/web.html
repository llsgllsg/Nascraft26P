Web extension

This page is not finished in the upstream documentation; placeholder only.

The original Nascraft mentions a web extension (browsing the market in a browser), but upstream never shipped a working implementation and Nascraft26P does not bundle a web panel.

If you need a web view, use the placeholders the plugin exposes on your own site, or export data with the commands.
