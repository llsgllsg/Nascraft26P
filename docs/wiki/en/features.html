Features overview

Nascraft ships with a pile of useful features; follow the links for details.

Feature index

  • Basic properties: initial price, aliases, elasticity, noise.
  • Price limits: hard limits and soft limits (support / resistance).
  • Taxation: default tax, per-item tax, Discord tax.
  • MiniMessage format: how item names and messages are written.
  • QQ bot: two ways in — OneBot v11 (personal QQ) and the official QQ bot (open-platform API v2). Both can quote prices, set alerts and announce trades (added by this fork).
  • Discord extension: bring the market into Discord.
  • Sell wands: right click to estimate, left click to sell.
  • Multi-currency: use PlayerPoints and friends as a second currency.
  • AdvancedGUI extension: a touch screen market.
  • Commands / placeholders: integrate with other plugins.
