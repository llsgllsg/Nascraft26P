Configuration

Basics: config.yml

config.yml holds the important settings: language, defaults, the Discord extension, sell wand behaviour and so on.

Config version and automatic upgrades

config.yml starts with a config-version field that marks the structure version of the file (do not edit it by hand).

  • On startup the plugin compares the config.yml on disk with the default one bundled in the jar.
  • If the file on disk is older: it is backed up as config-backup-<old version>-<time>.yml, then any new keys (comments included) are merged in. Your own values are always kept.
  • If the versions match: nothing is written, your file is left untouched.
  • If the file on disk is newer than the bundled one (for example you downgraded the plugin): the console warns and the file is not overwritten.

So after upgrading there is no need to compare configurations manually — just restart. To see what was merged, diff config-backup-*.yml against the new file.

How do I add items to the market?

The market lives in two files: items.yml and categories.yml.

To add an item you can edit both files by hand (write it into items.yml and attach it to a category in categories.yml), or use the in-game editor: /nascraft edit.

How do I change item properties?

Again, either edit items.yml by hand or use /nascraft edit.

Languages

The plugin ships with zh_CN language files (the Chinese translation is complete in this fork). Switch languages with the language field in config.yml. To change wording, edit plugins/Nascraft/lang/zh_CN.yml and run /nascraft reload.
