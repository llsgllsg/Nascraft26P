Sell wands

A convenient way to sell items straight to the market.

Nascraft has a built-in sell wand system. Enable it first:

# ...
sell-wands:
  enabled: true

Then you can configure your own wands. A wand has the following properties:

  • material: the physical item material.
  • display-material and lore: the displayed material and description text. [USES] and [PROFIT] can be used as placeholders (for wands with a use or profit limit).
  • enchanted: true / false, whether it gets the enchantment glint.
  • multiplier: the multiplier applied when selling.
  • cooldown: seconds between two uses, 3 by default.
  • uses: limit the number of uses.
  • max-profit: limit the total money the wand can generate (multiplied by multiplier).
  • permission: permission required to use the wand (optional).
  • currencies: restrict which currencies the wand works with.

Once configured, hand them out with /givesellwand [ID] or /givesellwand [player] [ID].

Here are the three wands that ship by default (edit, delete or add your own):

Tip: these are examples only, change them however you like.

  • BASIC WAND: 10 uses, requires nascraft.wand.basic.
  • PERMANENT WAND: unlimited uses and no profit cap, at the cost of a 0.5 multiplier (half the money), 300 second (5 minute) cooldown, requires nascraft.wand.advanced.
  • MILLONAIRE WAND: total profit of 1,000,000, 1.5 multiplier (+50%), requires nascraft.wand.millonaire.
# ...
sell-wands:
  enabled: true
  wands:
    # ID: just an identifier
    basic:
      material: 'stick'
      # recommended MiniMessage editor: https://webui.advntr.dev/
      display-name: '<b><gradient:#19e312:#a3e300>BASIC WAND</gradient></b>'
      lore:
        - '<b><gradient:#00eeff:#2e69ff>⏵ RIGHT CLICK</gradient></b> <color:#517d58>to estimate value.</color>'
        - '<b><gradient:#ff383b:#ff2403>⏵ LEFT CLICK</gradient></b> <color:#517d58>a container to</color>'
        - '<color:#517d58>sell all its content to the market!</color>'
        - ' '
        - '<color:#517d58>Uses left:</color> <b><color:#a3e300>[USES]</color></b>'
      # Maximum number of uses. A profit cap is also possible, see MILLONAIRE WAND.
      # With neither set the wand is unlimited, see PERMANENT WAND.
      uses: 10
      # Permission required to use the wand; leave empty to skip the check.
      permission: 'nascraft.wand.basic'

    permanent:
      material: 'blaze_rod'
      enchanted: true
      display-name: '<b><gradient:#e74cf5:#f51d41>PERMANENT WAND</gradient></b>'
      lore:
        - '<b><gradient:#00eeff:#2e69ff>⏵ RIGHT CLICK</gradient></b> <color:#8077ba>to estimate value.</color>'
        - '<b><gradient:#ff383b:#ff2403>⏵ LEFT CLICK</gradient></b> <color:#8077ba>a container to</color>'
        - '<color:#8077ba>sell all its content to the market</color>'
        - '<color:#8077ba>for <b><color:#ff2403>50%</color></b> of its value.</color>'
        - '<i><color:#343d66>⌛ 5 minutes of cooldown between uses.</color></i>'
        - ' '
        - '<b><gradient:#f51d41:#e74cf5>UNLIMITED USES</gradient><b>'
      multiplier: 0.5
      # currencies this wand can use
      currencies:
        - 'vault'
      # minimum cooldown between uses (seconds)
      cooldown: 300 # 300/60 = 5 minutes
      permission: 'nascraft.wand.advanced'

    millionaire:
      material: 'blaze_rod'
      enchanted: true
      display-name: '<b><gradient:#F57E00:#EFF551>MILLIONARIE WAND</gradient></b>'
      lore:
        - '<b><gradient:#ff383b:#ff2403>⏵ LEFT CLICK</gradient></b> <color:#85784D>to estimate value.</color>'
        - '<b><gradient:#00eeff:#2e69ff>⏵ RIGHT CLICK</gradient></b> <color:#85784D>a container to</color>'
        - '<color:#85784d>sell all its content to the market</color>'
        - '<color:#85784d>for <color:#EFF551>150%</color> its value.</color>'
        - ' '
        - '<color:#85784d>Left to sell:</color> <b>[PROFIT-LEFT]</b>'
      currencies:
        - 'vault'
      # the wand can generate at most 1,000,000$ in total (multiplier included)
      max-profit: 1000000
      multiplier: 1.5
      permission: 'nascraft.wand.millonaire'
      # remap the left / right clicks, 'none' disables one.
      # default: left click sells, right click estimates
      sell: 'right'
      estimate: 'left'
