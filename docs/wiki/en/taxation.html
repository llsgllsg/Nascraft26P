Taxation

Tip: keep tax rates low — heavy taxes discourage players from using the market.

Tax is a percentage taken (and destroyed) on every trade. It exists to stop players from profiting off short-term swings, such as buying and immediately selling (the first buy pushes the price up).

There are three kinds of tax, each configured separately for buying and selling:

  • Default tax: used when an item has no tax of its own.
  • Per-item tax: overrides the default for a single item.
  • Discord tax: the global rate used for trades made through Discord.

Default tax (config.yml):

market-control:
  # ...
  taxation:
    sell: 0.06 # 6% when players sell
    buy: 0.04 # 4% when players buy

Per-item tax (items.yml):

items:
  cobblestone:
    # ...
    tax:
      # 5% when buying cobblestone
      buy: 0.05
      # 10% when selling cobblestone
      sell: 0.1

Discord tax (config.yml):

discord-bot:
  # ...
  taxation:
    override: true
    buy: 0.04
    sell: 0.05
