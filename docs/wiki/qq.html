QQ 机器人（OneBot v11）

这是 Nascraft26P 新增 的功能，上游 Nascraft 没有。它让玩家在 QQ 群里查价、设提醒、绑定账号，也能把成交直接播报到群里。

它能做什么

功能 说明
查价 在群里或私聊发「行情 煤炭」，返回当前价格、库存和今日涨跌
价格提醒 到价后私聊提醒你，每个 QQ 最多 8 条
交易播报 大额成交、指定玩家的成交实时推送到指定群
账号绑定 QQ ↔ 游戏账号一对一绑定，权限与游戏内一致

支持的 OneBot 实现

协议是标准的 OneBot v11，原则上任何实现都能接：

  • 个人 QQ：NapCat、LLOneBot、Lagrange、go-cqhttp
  • QQ 官方机器人渠道：gensokyo、@onebots/adapter-qq 等 OneBot v11 适配器

机器人本身不随插件分发，需要你自己部署一个，并开启它的 HTTP API 与 HTTP 上报。

配置

在 config.yml 末尾的 onebot 段：

onebot:
  enabled: false
  # OneBot v11 HTTP API 地址（不要带 /send_private_msg 后缀）
  api-url: 'http://127.0.0.1:3000'
  # 与 OneBot 实现约定的 access token；留空表示不校验
  access-token: ''

  # 把游戏内成交播报到 QQ 群
  log-trades:
    enabled: false
    # 接收交易日志的群号，可以填多个
    group-ids: []

  # QQ 价格提醒
  alerts:
    enabled: false
    # 检查提醒的间隔（秒）
    check-interval: 60

  # 接收 OneBot 事件上报的 Webhook 服务
  webhook:
    enabled: false
    host: '127.0.0.1'
    port: 8765
    path: '/onebot'
    # 校验上报请求的密钥；留空或 SECRET 表示不校验
    secret: ''

  # 允许在 QQ 里使用的命令
  commands:
    enabled: true
    # 允许使用命令的群号；留空 = 所有群都允许（私聊始终允许）
    group-whitelist: []

port 注意别和其他插件（例如网页地图、面板）冲突；这是插件自己监听的端口。

连接步骤

  1. 部署机器人（以 NapCat / LLOneBot 为例），登录你的 QQ 小号。
  2. 在机器人后台打开 HTTP 服务（HTTP API），记下地址和端口，建议设置 access token。
  3. 在机器人后台配置 HTTP 上报（HTTP POST），地址填：

http://<服务器内网或公网 IP>:8765/onebot

如果 webhook.secret 不是空的，还要在机器人侧填上相同的 token / secret。

  1. 回到 config.yml，把 onebot.enabled、webhook.enabled 打开，api-url 填机器人地址，重启服务器。
  2. 控制台出现 [OneBot] Webhook 监听 http://…:8765/onebot 就算通了。

绑定账号

  1. 玩家在游戏里执行 /linkqq（别名 /qq，权限 nascraft.qq.linkable）。
  2. 插件返回一串 6 位绑定码，10 分钟内有效。
  3. 玩家用 QQ 私聊机器人发送：绑定 123456。
  4. 绑定成功后，各种查询和提醒都会发到该 QQ。

解绑：

  • 游戏内：/linkqq unlink
  • QQ 里：解绑

QQ 命令

私聊直接发；群里需要机器人能被叫到（或在白名单群里直接发）。

命令 说明
帮助 / help / 菜单 / ? 查看指令帮助
行情 <物品> / 价格 <物品> / price <物品> 查询价格、库存、今日涨跌
提醒 <物品> <价格> / alert <物品> <价格> 设置到价提醒（负数表示跌破）
提醒列表 / alerts 查看自己的提醒
取消提醒 <物品> / unalert <物品> 取消某条提醒
绑定 <绑定码> / bind <绑定码> 绑定游戏账号
解绑 / unlink 解除绑定

交易播报

打开 onebot.log-trades.enabled 并填好 group-ids 后，每笔成交会按下面的格式发到群里：

[TIME] [PLAYER] [ACTION] [AMOUNT] x [ITEM] = [WORTH]

可以改 langs/zh_CN.yml 里的 onebot_trade_line 自定义文案，[ACTION] 等占位符会被替换。

排错

现象 排查方向
群里发命令没反应 webhook.enabled 是否打开；机器人上报地址是否指向 http://IP:端口/onebot
返回 403 webhook.secret 与机器人侧填的 token 不一致
返回 405 上报方式用了 GET，必须是 POST
能收消息但发不出去 api-url 填错，或机器人 HTTP API 未开启
群里能用、私聊不行 私聊也走同一个 Webhook，检查机器人是否把私聊消息也上报
提示"该 QQ 已经绑定" 一个 QQ 只能绑一个游戏账号，先在 QQ 里 解绑

服务器到机器人的网络必须是通的：如果机器人和服务器不在同一台机器，api-url 要填可达地址（或走内网穿透）。
