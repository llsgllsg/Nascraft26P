Nascraft26P Documentation

Note: this page is the English version of the Nascraft Wiki migration, revised for Nascraft26P (this fork).

What is this

Nascraft is a plugin that brings a modern economy to Minecraft servers. It replaces traditional admin shops with a set of rules:

  • Dynamic prices: every item has an initial price, stock, elasticity and noise, so prices float with supply and demand and try to stay at a fair level.
  • Many ways to trade: in-game GUI, commands, menus, plus Discord and QQ bot extensions.

Nascraft26P is a localized and compatibility-maintained fork of Nascraft: it follows the latest Paper versions (since v26.4.5.2 a single jar covers 1.21.11 to 26.3 and picks the GUI backend at startup), ships with Chinese translations, and adds a QQ bot integration (both OneBot v11 and the official QQ open-platform API v2) for Chinese servers.
