Commands

Admin commands

Command Permission Description
/nascraft edit nascraft.admin Open the market editor menu
/nascraft reload nascraft.admin Reload items.yml and categories.yml
/nascraft logs global nascraft.admin Browse every trade on the server in a GUI
/nascraft logs <player name or UUID> nascraft.admin View all trades of a player
/nascraft logs <item identifier> nascraft.admin View all trades of an item
/nascraft cpi nascraft.admin Query the consumer price index (CPI)
/nascraft stop nascraft.admin Pause the market (no trading while paused)
/nascraft resume nascraft.admin Resume the market
/nascraft save nascraft.admin Force a save
/nascraft info nascraft.admin Show a summary: CPI, tax rates and so on
/givesellwand [wand ID] nascraft.admin Give yourself a sell wand

Player commands

Command Permission Description
/market nascraft.market and nascraft.market.gui Open the market GUI
/market [buy/sell] [material] [amount] nascraft.market Buy or sell directly from a command
/sell nascraft.sellinv Open the selling menu
/sellhand nascraft.sellhand Sell the item in your hand
/sellall [material/everything] nascraft.sellall Sell every item of that material, or everything sellable
/link [code] nascraft.linkable Link your account with the built-in system
/worth nascraft.worth See how much the item in your hand is worth

/web register [password] belongs to the unfinished web extension; ignore it for now.

Console commands

Command Description
market [buy/sell] [material] [amount] [player] Force a player to buy / sell
sellmenu [player] Open the selling menu for a player
givesellwand [wand ID] [player] Give a wand to a player
market category [category identifier] [player] Open a category menu for a player

Discord commands

Command Required role Description
/balance none Show your balance
/inventory none Show your Discord virtual inventory
/link none Start the linking flow
/alert [identifier] [price] none Set a price alert
/alerts none List your alerts
/remove-alert none Pick and remove an alert
/seeinv [user ID] admin role View someone else's inventory
/seebal [user ID] admin role View someone else's balance
/stop and /resume admin role Pause / resume the whole market
