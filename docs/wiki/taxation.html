税收

提示：税率尽量别太高，税太重会打击玩家使用市场的积极性。

税收是每笔交易中被系统扣掉（并实际销毁）的百分比金额。它存在的意义是防止玩家利用短期波动套利——比如买入后立刻卖出赚差价（第一次买入会把价格顶上去）。

税收分三种，每种都按「买 / 卖」两个方向分别设置：

  • 默认税：没有单独设置物品税时使用。
  • 按物品税：为单件物品覆盖默认税率。
  • Discord 税：通过 Discord 交易时使用的全局税率。

默认税（config.yml）：

market-control:
  # ...
  taxation:
    sell: 0.06 # 玩家卖出时收 6%
    buy: 0.04 # 玩家买入时收 4%

按物品税（items.yml）：

items:
  cobblestone:
    # ...
    tax:
      # 买入原石收 5%
      buy: 0.05
      # 卖出原石收 10%
      sell: 0.1

Discord 税（config.yml）：

discord-bot:
  # ...
  taxation:
    override: true
    buy: 0.04
    sell: 0.05
