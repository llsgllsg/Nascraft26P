AdvancedGUI extension

Place an interactive "market board" in your world that shows price charts.

Nascraft ships a layout extension for AdvancedGUI. AdvancedGUI is a paid plugin by Leoko that creates touch screen interfaces in your server — highly recommended even without Nascraft.

The screen roughly looks like this: items and the "sell" action on the left, a price chart in the middle, the inventory interface at the bottom.

Placing the screen

  1. Install AdvancedGUI (purchase, then drop the jar into plugins/ like any other plugin).
  2. Make sure its dependencies are present (ProtocolLib).
  3. With both AdvancedGUI and Nascraft installed, restart the server and check this option in config.yml:

yaml auto-resources-injection: true

Note: the upstream docs misspell this key (auto-resources-injectio); go with whatever config.yml actually generates.

  1. Place the interface with /ag place Nascraft.

Without AdvancedGUI installed, the startup log shows AdvancedGUI is not installed. That is expected and does not affect any other feature.
