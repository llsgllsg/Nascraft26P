﻿# 命令

管理员命令

命令 权限 说明
/nascraft edit nascraft.admin 打开市场编辑器菜单
/nascraft reload nascraft.admin 重新加载 items.yml 与 categories.yml
/nascraft logs global nascraft.admin 用 GUI 查看全服交易
/nascraft logs <玩家名或 UUID> nascraft.admin 查看某个玩家的全部交易
/nascraft logs <物品标识符> nascraft.admin 查看某件物品的全部交易
/nascraft cpi nascraft.admin 查询消费者物价指数（CPI）
/nascraft stop nascraft.admin 暂停市场（暂停期间不能买卖）
/nascraft resume nascraft.admin 恢复市场
/nascraft save nascraft.admin 强制保存
/nascraft info nascraft.admin 查看 CPI、税率等概况
/givesellwand [魔杖ID] nascraft.admin 给自己发一把指定的出售魔杖

玩家命令

命令 权限 说明
/market nascraft.market 和 nascraft.market.gui 打开市场 GUI
/market [buy/sell] [材质] [数量] nascraft.market 用命令直接买卖
/sell nascraft.sellinv 打开回收菜单
/sellhand nascraft.sellhand 卖出手中物品
/sellall [材质/everything] nascraft.sellall 卖出指定材质的全部物品，或所有可卖物品
/link [验证码] nascraft.linkable 用内置系统绑定账号
/worth nascraft.worth 查询手中物品能卖多少钱

/web register [密码] 属于尚未完成的网页扩展，当前版本请忽略。

控制台命令

命令 说明
market [buy/sell] [材质] [数量] [玩家] 强制某玩家买入 / 卖出
sellmenu [玩家] 为某玩家打开回收菜单
givesellwand [魔杖ID] [玩家] 发给某玩家指定魔杖
market category [分类标识符] [玩家] 为某玩家打开某个分类菜单

Discord 命令

命令 需要的角色 说明
/balance 无 查询余额
/inventory 无 查看 Discord 虚拟背包
/link 无 开始绑定流程
/alert [标识符] [价格] 无 设置价格提醒
/alerts 无 查看已有提醒
/remove-alert 无 选择并删除一条提醒
/seeinv [用户ID] 管理角色 查看他人背包
/seebal [用户ID] 管理角色 查看他人余额
/stop 与 /resume 管理角色 暂停 / 恢复整个市场
