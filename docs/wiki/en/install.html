Installation

Requirements

You only need one jar: Nascraft-<version>.jar. At startup the plugin reads the server version and picks the matching GUI backend (InvUI 1.x or 2.x) by itself — no more per-version jars.

Server version Java GUI backend (auto-selected)
Paper / Purpur 1.21.11 21 InvUI 1.x
Paper / Purpur 26.1.1 / 26.1.2 25 InvUI 2.x
Paper / Purpur 26.2 25 InvUI 2.x
Paper / Purpur 26.3 25 InvUI 2.x
Paper / Purpur 26.4+ 25 Pending

Notes:

  • Every library (bStats, InvUI 1.x / 2.x, item-nbt-api) is bundled in the jar, so it runs on a clean server dropped into plugins/.
  • Only Spigot / Paper / Purpur are supported; other forks such as Mohist are not guaranteed.
  • Since 26.4.5.2 there are no per-version jars anymore. Delete the old ones and keep a single jar.
  • The 26.1 series ships only 26.1.1 (alpha) and 26.1.2 (stable); there is no plain "26.1" build.
  • The startup log prints the backend in use, e.g. GUI backend: invui 2.x (Bukkit 26.1.2-..., Java 25...), which is how you can confirm detection worked.

Installation steps

Step 1: check dependencies

Make sure Vault and an economy plugin (EssentialsX, for example) are installed; you can get Vault here (without Vault the plugin still starts, but economy features stay disabled).

Step 2: download the jar

Grab the latest Nascraft-<version>.jar from the Releases page and put it into your server's plugins/ folder.

Step 3: restart the server

The plugin generates its configuration on first start; continue with Configuration.

When you upgrade, config.yml is merged automatically using its config-version: the old file is backed up as config-backup-*.yml first, your own values and the existing comments are preserved, so there is no need to diff anything by hand.

Step 4 (optional): extensions

  • AdvancedGUI: place an in-game touch screen market, see the AdvancedGUI extension.
  • Discord extension: bring the market into Discord, see the Discord extension.
  • QQ bot: two ways in — a personal QQ account through the OneBot v11 bridge, or an official QQ bot through the open-platform API v2. Both can quote prices, show holdings and announce trades in QQ groups or private chats, see QQ bot.
