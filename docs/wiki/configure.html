配置

基础配置：config.yml

config.yml 里有几个重要字段：语言、默认值、Discord 扩展、出售魔杖的行为等等。

配置文件版本与自动升级

config.yml 顶部有一个 config-version 字段，用于标记这份配置的结构版本（请勿手动修改）。

  • 插件启动时会比较磁盘上的 config.yml 与 jar 内置的默认配置。
  • 如果磁盘版本更旧：先把旧文件备份为 config-backup-<旧版本>-<时间>.yml，再把新版本新增的配置项（含中文注释）合并进去；你改过的值一律保留。
  • 如果版本相同：完全不写盘，不会动你的文件。
  • 如果磁盘版本比插件内置的还新（比如你降级了插件）：只在控制台告警，不覆盖文件。

所以升级插件后不需要手动对比配置，直接重启即可；想确认合并了哪些键，diff 一下 config-backup-*.yml 和新文件就行。

怎么往市场里加物品？

市场内容分成两个文件：items.yml 和 categories.yml。

要新增物品，可以手动改这两个文件（两个都要改：既写进 items.yml，也要挂到 categories.yml 的某个分类下），也可以直接用游戏内菜单：/nascraft edit。

怎么改物品属性？

同样两种方式：手动编辑 items.yml，或者用 /nascraft edit。

多语言

插件自带 zh_CN 语言文件（本版本已完整汉化），在 config.yml 的 language 字段里切换即可。修改文案直接改 plugins/Nascraft/lang/zh_CN.yml，改完 /nascraft reload 生效。
