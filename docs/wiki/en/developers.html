Depending on Nascraft in your project

Note: upstream marks this feature as "WIP: NOT WORKING CURRENTLY".

Maven repository:

<repository>
    <id>jitpack.io</id>
    <url>https://jitpack.io</url>
</repository>

Dependency:

<dependency>
    <groupId>com.github.Bounser</groupId>
    <artifactId>Nascraft</artifactId>
    <version>version</version>
</dependency>

Gradle (at the end of the root build.gradle):

dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        mavenCentral()
        maven { url 'https://jitpack.io' }
    }
}

dependencies {
    implementation 'com.github.Bounser:Nascraft:version'
}

Replace version with the latest version number.
