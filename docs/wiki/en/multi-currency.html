Multi-currency

Nascraft has a built-in multi-currency system. In theory any number of currencies is supported, as long as the currency can expose a PlaceholderAPI placeholder and deposit / withdraw commands.

Note: if you plan to use the Discord extension, those commands and placeholders must work while the player is offline.

The default currency is Vault and can be changed in the configuration. Example:

# ...
currencies:
  # the currency every item uses by default.
  # also the default currency for features such as Discord inventory upgrades.
  default-currency: 'vault'

  suppliers:

    # Vault is required! This is the default currency.
    vault:
      format: "<gradient:#f09947:#feed81>[AMOUNT]$</gradient>"
      not-enough: "<gradient:#FB6363:#C4B3FD>✘ You don't have enough money to buy that!</gradient>"
      decimal-positions: 3
      top-limit: 9999999
      low-limit: 0.005

    #################################################################

    # an example of another currency:
    player-points:
      deposit-cmd: 'playerpoints:p give [USER-NAME] [AMOUNT]'
      withdraw-cmd: 'playerpoints:p take [USER-NAME] [AMOUNT]'
      balance-placeholder: '%playerpoints_points%'
      not-enough: "<gradient:#FB6363:#C4B3FD>✘ You don't have enough points to buy that!</gradient>"
      format: "<gradient:#ba24ff:#e8d1ff>[AMOUNT]p</gradient>"
      decimal-positions: 0
      top-limit: 9999
      low-limit: 10

As in the example, every currency other than Vault needs a unique identifier (player-points above) and these properties:

  • deposit-cmd: the command that adds money to a player's account; supports the [USER-NAME] and [AMOUNT] placeholders.
  • withdraw-cmd: the command that takes money from a player's account; same placeholders.
  • balance-placeholder: the PlaceholderAPI placeholder returning the player's balance; must be a bare number without formatting.
  • not-enough: the message shown when the balance is too low.
  • format: how amounts are displayed, with the [AMOUNT] placeholder.
  • decimal-positions: how many decimals prices in this currency keep. PlayerPoints only supports integers, hence 0.
  • top-limit: hard upper limit for prices in this currency.
  • low-limit: hard lower limit for prices in this currency.
