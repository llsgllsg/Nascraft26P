价格限制

价格可以有两种限制：

  • 硬限制（Hard limits）：价格绝不可能越过这条线。在 config.yml 里配置，是每种货币的属性。
  • 软限制（Soft limits）：价格可以越界，但在开启噪声时会逐渐被拉回区间内。下界叫「支撑（Support）」，上界叫「压力（Resistance）」。

硬限制（按货币配置）：

currencies:
  # ...
  vault:
    # 其他选项...
    # 下面这个例子中，所有以 vault 为货币的物品都受这些限制：
    # 价格无论如何都不会高于 9999，也不会低于 0.05。
    top-limit: 9999
    low-limit: 0.05

  # 其他选项...

软限制（按物品配置）：

items:
  cobblestone:

    # 其他属性...

    support: 0.01
    resistance: 0.1

调参建议

  • 硬限制是「安全阀」，建议设在玩家能接受的极端值，防止刷物品把价格打穿。
  • 支撑价 / 压力价用来塑造市场区间：例如把钻石的支撑价设在一个体面的位置，避免玩家把价格砸到底部。
  • 软限制只在噪声开启时生效；关掉噪声后价格只受买卖影响。
