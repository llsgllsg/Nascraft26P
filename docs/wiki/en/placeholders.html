Placeholders (PlaceholderAPI)

Install PlaceholderAPI before using these placeholders.

Placeholder Returns
%nascraft_price_IDENTIFIER% Current price of the item
%nascraft_buyprice_AMOUNT_IDENTIFIER% Price of buying the given amount
%nascraft_sellprice_AMOUNT_IDENTIFIER% Price of selling the given amount
%nascraft_stock_IDENTIFIER% Internal stock of the item
%nascraft_change_IDENTIFIER% Price change (%) over a period
%nascraft_linked% Whether the player is linked: true / false
%nascraft_discordid% The linked Discord ID
%nascraft_cpi% Current inflation rate (%)

Where:

  • IDENTIFIER is the identifier used in items.yml; mainhand also works and means the item in the player's main hand.
  • AMOUNT is an integer amount.
