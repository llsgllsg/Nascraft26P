开发者

在你的项目里引用 Nascraft

注意：原版文档标注该功能「尚未完成 / 当前不可用」（WIP: NOT WORKING CURRENTLY）。

Maven 仓库：

<repository>
    <id>jitpack.io</id>
    <url>https://jitpack.io</url>
</repository>

依赖：

<dependency>
    <groupId>com.github.Bounser</groupId>
    <artifactId>Nascraft</artifactId>
    <version>version</version>
</dependency>

Gradle（在根 build.gradle 末尾）：

dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        mavenCentral()
        maven { url 'https://jitpack.io' }
    }
}

dependencies {
    implementation 'com.github.Bounser:Nascraft:version'
}

把 version 换成最新版本号即可。

可用的监听事件

  • BuyItemEvent
  • SellItemEvent
  • TransactionCompletedEvent

市场管理器

MarketManager 提供市场数据（价格、库存等）的读取与操作接口。这部分上游文档仍在建设中。
