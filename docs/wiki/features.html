﻿# 功能总览

Nascraft 有一大堆实用功能，点进去可以看细节。

功能索引

  • 基础属性：初始价、别名、弹性、噪声。
  • 价格限制：硬限制与软限制（支撑价 / 压力价）。
  • 税收：默认税、按物品税、Discord 税。
  • MiniMessage 格式：物品名和提示文本的写法。
  • QQ 机器人：在 QQ 群里查价、设提醒、接收成交播报（本项目新增）。
  • Discord 扩展：把市场搬进 Discord。
  • 出售魔杖：右键估值、左键回收。
  • 多货币系统：用 PlayerPoints 等作为第二种货币。
  • AdvancedGUI 扩展：触屏行情界面。
  • 命令 / 变量：自行接入其他插件。
