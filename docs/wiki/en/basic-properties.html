Basic properties

Every item has a set of configurable properties:

  • initial-price: required for every item. Guess a reasonable starting value; once the market forms its own valuation, the initial price matters less and less.
  • alias: the item name players see. When omitted, the official Minecraft translation is used (e.g. diamond becomes 钻石 with the Chinese language file); a configured alias always wins.
  • elasticity: how easily and how far the price moves.

Tip: for items that will not trade much (high value, rare, and so on), raise the elasticity.

  • noise-intensity: how much random fluctuation affects the price.

Careful: elasticity multiplies noise. Raise elasticity and the price will swing harder too.

An example item (items.yml):

items:
  # item identifier
  cobblestone:
    # required:
    initial-price: 0.05
    # optional:
    alias: 'Cobble'
    # optional:
    elasticity: 0.5
    # optional:
    noise-intensity: 1.4
    # ...

About noise

Noise is a "jitter a little every minute" mechanism that mimics the chatter of a real market. Prices also drift while nobody is trading, so even short time spans show movement. If you want calmer prices, lower noise-intensity or set it to 0.
